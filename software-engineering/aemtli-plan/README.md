# Ämtli – WG-App (Software Engineering, Gruppenarbeit HS26)

Gruppenprojekt im Fach Software Engineering: eine Django-Web-App für Wohngemeinschaften mit Ämtliplan (wöchentliche Rotation), gemeinsamen Ausgaben mit Saldo und Einladung per Code. Lead der Gruppe ist Ray; der Code liegt im Repo [R4yl1n/Aemtli_Plan](https://github.com/R4yl1n/Aemtli_Plan).
